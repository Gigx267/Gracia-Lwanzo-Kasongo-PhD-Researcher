🚀 Features
Responsive Design – Mobile-first layout with collapsible navigation.

Professional Aesthetic – Cream/burgundy/navy color palette with serif and sans-serif typography.

Smooth Scrolling – Anchor links for in-page navigation.

Interactive Elements – Hover effects, filterable publication list, form submission demo.

Accessible – Semantic HTML, ARIA labels, and focus states.

Lightweight – No build step; all dependencies loaded via CDN.

Dynamic Icons – Feather Icons automatically replaced on page load.

Google Fonts – Newsreader, Inter, Oswald, and Cinzel for a refined academic look.

Embedded Map – OpenStreetMap iframe for location context on the contact page.

🧑‍💻 Setup & Usage
Clone or download the repository.

Ensure all .html files and the VX.PNG image are in the same directory.

Open index.html in any modern web browser.

No build tools or server required — it’s a pure static site.

Optional: For local development with live reload, you can use a simple HTTP server, e.g.:

bash
python3 -m http.server 8000
Then visit http://localhost:8000.

🎨 Customisation
Colors & Fonts – Modify the tailwind.config object inside each HTML file to change the palette or typography.

Content – Update text, images, and links directly in the HTML files.

Publications Filter – The data-category attributes on .pub-item elements control filtering (values: journal, chapter, conference, thesis). Adjust or add categories as needed.

Contact Form – The form is a static demo; to make it functional, connect it to a backend service (e.g., Formspree, Netlify Forms) or update the action attribute.

Map – Replace the OpenStreetMap iframe src with your own location coordinates.
